## Goal

Monetize the shipped journey product with the **smallest paid slice**: free users keep path select + **Gather Documents**; paid users unlock **Apply** + **After Arrival** via a **StoreKit 2 one-time** entitlement verified **server-side** — without gating auth, export, delete, or purge, and without touching `nomade-prod`.

**Complete when:**

1. Migration lands `internal.billing_events` + `internal.entitlements` on **local + `nomade-dev` only** (**never `nomade-prod`**).  
2. `GET /api/billing/entitlement` returns derived entitlement; `POST /api/billing/app-store/transactions` verifies a StoreKit transaction / JWS and upserts event + entitlement.  
3. Journey checklist marks free vs paid access; free user can PATCH Gather Documents steps; Apply / After Arrival PATCH → `403 ENTITLEMENT_REQUIRED`.  
4. Entitled (purchase or restore) user can write all steps; entitlement survives relaunch (server SoT).  
5. Export `billing` filled with entitlement + transaction ids (no JWS); `wipeBilling` no longer a pure no-op (policy-compliant).  
6. Thin iOS: local StoreKit config + paywall + purchase + restore; Journey wires locked phases → Unlock CTA.  
7. Auth / export / delete / purge still work **without** entitlement.  
8. Docs + unit tests + CI green; one task ID per PR; secrets in Keeper only; no secrets in chat.  
9. **No** Stripe primary, RevenueCat required, AI quotas, full ASSN reconcile job, RAG, multi-country, or Production schema apply.

## Schema sketch (migration — local + nomade-dev only)

```sql
-- conceptual; Theo lands a numbered supabase migration

create table internal.billing_events (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null references internal.users (id),
  source text not null default 'app_store',
  product_id text not null,
  transaction_id text not null,
  original_transaction_id text,
  event_type text not null, -- purchase | restore | refund | …
  occurred_at timestamptz not null,
  raw_ref text,             -- opaque / hash — avoid full JWS in routine storage
  created_at timestamptz not null default now(),
  unique (source, transaction_id)
);

create table internal.entitlements (
  user_id uuid not null references internal.users (id),
  entitlement_id text not null, -- e.g. journey_full
  status text not null check (status in ('active', 'inactive')),
  source_transaction_id text,
  granted_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  primary key (user_id, entitlement_id)
);

create index billing_events_user_id_idx on internal.billing_events (user_id);
```

**Access:** service client in Next.js after `requireAccess` — **no** client-direct table grants.  
**Apply:** local + `nomade-dev` only. **`nomade-prod` forbidden.**

## API contracts

### `GET /api/billing/entitlement`

| | |
|---|---|
| **Auth** | `requireAccess` + active account |
| **Success 200** | `{ entitlements: [{ id, status, grantedAt?, updatedAt? }], requestId }` |

### `POST /api/billing/app-store/transactions`

| | |
|---|---|
| **Auth** | `requireAccess` + active |
| **Body** | signed transaction payload / JWS (shape Theo aligns with StoreKit 2 + App Store Server API) |
| **Success 200** | updated entitlement + requestId |
| **Errors** | `400` bad/unverified; `401`/`403`/`410` as account routes |

### Journey enforcement

- Checklist GET: each phase/step `access: "free" | "paid"`; top-level `entitlement: { journeyFull: boolean }`.  
- PATCH locked step without entitlement → `403` `ENTITLEMENT_REQUIRED`.  
- Free steps remain fully writable.

### Optional thin ASSN

`POST /api/billing/app-store/notifications` — verify JWS; upsert event; recompute entitlement. Cap default: ship thin in backend PR **or** F3.1b if blocked on ASC setup.
